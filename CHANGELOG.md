# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2024-10-18

### Added
- Initial release of ElevenLabs React Chat component
- Real-time voice conversation support via ElevenLabs API
- React component with TypeScript support
- Built-in UI with customizable styling
- Automatic message handling and conversation management
- Connection status indicators
- Error handling with callbacks
- Responsive mobile-friendly design
- Complete example application
- Comprehensive documentation and API reference
